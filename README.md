# 메트로 군웅전 — v0.7 Tactical Edition

서울 지하철역을 도시로, 지하철 노선을 보급망으로 활용한 싱글플레이 턴제 전략 운영 게임입니다. 삼국지 4의 내정·인재·전쟁 운영 감각을 참고하되 게임 캐릭터와 아트 리소스는 새로 제작했습니다.

## 플레이
- https://eoensms-ltizen.github.io/metro-warlords/
- index.html 하나만으로 실행 가능 (HTML에 스타일·스크립트·이미지 모두 포함). CDN/외부 서버 불필요.
- 모바일에서는 가로 화면을 권장. 자동 저장이 아닌 '저장' 명령을 사용합니다.

## v0.7
- 10×8 전술 격자: 부대 선택, 이동, 공격, 돌격, 방어, 지원, 엄폐·장애물, 지휘 본부 2라운드 점령 또는 부대 격퇴
- 수동 전투와 AI 자동 전투가 동일한 격자·피해·승리 규칙 사용. 전투 중 자동/수동 전환, 자동 진행 일시정지
- 출진 편성에서 최대 4명 지휘관·병종·병력 지정, 전후 포로 처우 및 전략 지도 결과 반영
- 지원 요청한 물자·병력의 수송열차 이동 표시 및 구간·개월 기반 도착
- 월간 진행: 역사별 지도 포커스와 보고관, 재생·일시정지·배속·건너뛰기
- 이미지 생성 기반 일러스트와 세력 문장, Web Audio 합성 효과음 및 음소거
- 기존 내정/도시 목표/자동 위임/인재 등용/포로 관리/수송/저장·불러오기 유지

## 개발 및 QA
- GitHub Pages는 main push 후 .github/workflows/pages.yml로 자동 배포합니다.
- JavaScript 문법 검사 및 Node 가상 브라우저 DOM 스텁에서 초기화, 전술 전투 80타일, 부대 이동, 라운드 종료, 월간 보고를 검증했습니다.
- 실제 모바일 브라우저 렌더링·지속 플레이·장시간 밸런스·접근성은 별도 QA가 필요합니다.
- 이 버전은 **상용 출시판이 아닌 통합 플레이 데모**입니다. 삼국지 4의 저작권 아트나 음원은 포함하지 않습니다.
