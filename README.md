# 메트로 군웅전 v0.3

서울 2호선 남부 12개 역을 두고 경쟁하는 오프라인 싱글플레이 턴제 전략 게임.

## 플레이

`index.html`을 실행하거나 GitHub Pages로 배포합니다. 별도 빌드·서버·외부 라이브러리는 필요하지 않습니다.

## v0.3 추가 규칙

- **재야 등용**: 8명의 무소속 인재 중 한 명을 지정하고 역의 담당 인재가 등용 시도. 자금 120, 행동 1회 소모. 실패 가능.
- **포로 관리**: 역사 점령 시 일부 적 장수가 포로가 됩니다. `인재·포로 관리`에서 설득(자금 100+행동 1회, 성공률은 능력/충성에 따라 변화)하거나 석방할 수 있습니다. 포로로 잡히지 않은 장수는 가능한 역으로 후퇴하고, 소속 역이 전혀 없으면 재야가 됩니다.
- **도시 목표**: 역마다 내정·병력 생산·훈련·민심·전선 지원 선택.
- **행동 위임**: `다음 달 진행`을 누르면 사용하지 않은 인재 행동만 해당 역의 목표에 맞춰 수행. 자금 또는 물자가 부족한 경우 자동 행동 없음. 기본값 위임 켜짐.
- **전선 지원 목표**: 연결된 전초기지로 병력과 물자를 보냄. 전초기지로 지정된 역 자체에서 전선 지원 목표를 설정하면 다른 연결 전초기지가 없으므로 대기합니다.
- **훈련**: 병력 훈련도는 해당 역의 공격/방어 전투 효율에 반영.
- **민심**: 민심은 월간 자금 수입에 영향을 줍니다.

## 전략 루프

강남역에서 경제와 인재를 육성 → 후방 거점에 병력 모집 목표/위임 → 전초기지 수송 → 인접 역 점령 → 포로 설득 및 인재 재배치 → 새로운 도시 목표 설정.

## GitHub Pages 배포

1. GitHub에서 공개 저장소 `metro-warlords`를 생성합니다.
2. 이 폴더의 내용을 저장소 루트에 업로드하고 `main` 브랜치에 커밋합니다. **`.github/workflows/pages.yml`도 포함**해야 합니다.
3. 저장소 `Settings → Pages → Build and deployment → Source`에서 **GitHub Actions**를 선택합니다.
4. `Actions` 탭에서 배포 완료를 확인합니다.
5. 기본 공개 주소는 `https://GITHUB_USERNAME.github.io/metro-warlords/`입니다. 정확한 주소는 배포 로그에서 확인합니다.

GitHub 저장소 소유자 인증이 필요하므로, 이 ZIP 자체를 전달하는 것만으로 공개 URL이 생성되지는 않습니다.

## 저장 호환성

v0.3은 새 저장 키를 사용하며 v0.2 저장 파일을 자동으로 승계하지 않습니다. 브라우저별로 저장 데이터가 분리됩니다. 단순 HTML은 `localStorage`를 사용하며 모바일 파일 실행 환경에 따라 저장 기능이 제한될 수 있으므로 HTTPS 배포를 권장합니다.

## 구현 범위 제한

현재 전투는 자동 시뮬레이션입니다. 직접 지휘 전술 맵, 본격 외교, 복잡한 보급망과 AI 인재 관리는 아직 미구현입니다.

## v0.4 — 전쟁 편성과 세력 턴 보고

- 출진 편성: 동일 역의 행동 가능한 지휘관 최대 4명 선택, 선택한 첫 지휘관을 총대장으로 선임
- 부대 임명: 지휘관별 기동대·경비대·지원대와 병력 50명 이상 배정, 출진역 잔류 30명 및 비축 물자 제한 적용
- 전투 결과: 부대별 잔존 병력과 12라운드 기록 확인. 병종 구성과 통솔 평균이 전투력에 반영됨
- 전후 처우: 승전 직후 포로를 발견하면 즉시 등용(성공률 판정)·석방·구금을 순서대로 결정
- 월간 운영 보고: 우리 도시 위임 → 도심협의회 행동 → 서부개척단 행동 → 12개 역사 월말 결산 → 전체 합산을 단계별로 표시
- 적 세력 역 정보: 각 역사에서 전력 분위기·민심·방어 경향 및 상대 정보 확인
- v0.4는 저장 키가 변경되어 v0.3 자동 저장을 자동으로 가져오지 않음

### 기술 / 테스트

정적 `index.html`로 배포합니다. 별도 서버나 외부 CDN이 필요하지 않습니다. `node smoke-test.cjs` 및 `node test-v04.cjs`로 초기화·위임·저장·부대 출진·포로 처우·월간 보고를 확인했습니다. 이 테스트는 브라우저 렌더링 전체 검증을 대체하지 않습니다.
